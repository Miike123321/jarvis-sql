# J.A.R.V.I.S. SQL Assistant

Два интерфейса для Gemini и OpenAI-совместимого Omniroute: FastAPI с веб-чатом
и отдельное Streamlit-приложение. Оба провайдера подключены к инструменту
выполнения безопасных `SELECT` к Microsoft SQL Server. Создание таблиц,
представлений и индексов требует отдельного подтверждения.

## Настройка

Нужен Python 3.10+ и доступ к Microsoft SQL Server. В корне проекта создайте виртуальное
окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

На каждом компьютере создайте локальный `.env` по образцу `.env.example` и
заполните `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`, а также ключ
выбранного провайдера модели.
Не переносите секреты в репозиторий и не перезаписывайте существующий `.env`
образцом. Файлы с ключами и локальные настройки исключены из Git. Чтобы
подключиться с другого компьютера, ему также нужен сетевой доступ к выбранному
провайдеру модели и к указанному серверу SQL Server
(например, через корпоративную сеть или VPN).

Настройки БД можно задать в `.env` или сохранить через боковую панель
Streamlit. Для Gemini задайте `GEMINI_API_KEY` и при необходимости
`GEMINI_MODEL`. Для Omniroute задайте `OMNIROUTE_API_KEY` и, при необходимости,
`OMNIROUTE_BASE_URL` (по умолчанию используется `http://localhost:20128`).
Создайте отдельную учётную запись SQL Server с минимальными правами: только
нужные разрешения на чтение и, если требуется, разрешения на подтверждаемые
операции создания объектов.

## Запуск

Из этой папки выполните:

```bash
python -m uvicorn jarvis_backend:app --host 127.0.0.1 --port 8000
```

Откройте <http://127.0.0.1:8000>. Проверить настройки можно на
<http://127.0.0.1:8000/health>. `127.0.0.1` оставляет сервер доступным только
на этом компьютере.

## Альтернатива: Streamlit

Streamlit использует те же `.env` и настройки Gemini/Omniroute, но предоставляет
отдельный Python-интерфейс. В нём можно добавлять задачу несколькими частями и
отправлять их ассистенту одним нажатием:

```bash
python -m streamlit run streamlit_app.py
```

Откройте <http://localhost:8501>. На Windows активируйте окружение командой
`.venv\Scripts\activate` вместо `source .venv/bin/activate`.

## Ограничения

- Поддерживается Microsoft SQL Server (порт по умолчанию 1433).
- Для чтения допускается один `SELECT` (включая CTE), без команд записи и
  `SELECT INTO`; результат ограничен 100 строками.
- Gemini может выполнить до 25 раундов вызовов SQL-инструмента на одно сообщение. При
  достижении лимита приложение запрашивает частичный итог и отмечает его как
  неполный; для продолжения разбейте задачу на части.
- Интерфейс не может подменить SQL при подтверждении: сервер хранит запрос и
  выдаёт одноразовое подтверждение, действительное пять минут.
- Для подтверждения разрешены только одиночные `CREATE TABLE`, `CREATE VIEW` и
  `CREATE INDEX`; `DROP`, `ALTER`, `UPDATE`, `DELETE` и `INSERT` не выполняются.
- Локальный файл настроек содержит ключи доступа. Не публикуйте его, ограничьте
  права учётной записи БД и замените ключи, если они попали в общий доступ.
